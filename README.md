# montecristiao.com

蒙特克里斯府——montecristiao 伯爵的个人站点。第一人称探索式静态网站。

## 结构

- `index.html` — 全站（场景、动线、交互均为单文件内实现）
- `assets/` — 网页用图（WebP，源图与目录见 `..\视觉资产\`）

## 动线

前院 → 穿堂（访客簿 / 平面图 / 锁门：画廊·沙龙·地窖）→ 大楼梯 → 贵族层平台（书房 / 锁门：大客厅·三楼）→ 书房（真油画场景：伯爵·案上文稿·藏书批注）

## 部署

静态文件，无构建步骤。托管目标：Cloudflare Pages / GitHub Pages（由 GitHub 仓库驱动，见项目 README 的部署记录）。

## 纪律

- 场景图替换：只换 `assets/` 文件或 CSS 背景，不动交互逻辑。
- 新内容 = 新场景或新文稿条目；锁门纪律见《府邸设计概念-v0.1.md》。
- 访客数据只用 localStorage，零收集、零账号。
